# Contributing

Thanks for helping make PunyHuman better.

1. Search existing issues before opening a new one.
2. Fork the repository and create a focused branch from `main`.
3. Run `npm run check` before committing.
4. Keep tools local-first: no telemetry, uploads, or hidden network requests.
5. Open a pull request explaining the problem, solution, testing, and accessibility impact.

## Design principles

- Prefer browser standards and small modules over dependencies.
- Preserve keyboard access and WCAG AA contrast.
- Include tests for transformations and edge cases.
- Keep pull requests narrow enough to review confidently.
