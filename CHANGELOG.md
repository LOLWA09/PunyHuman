# Changelog

All notable changes to PunyHuman are documented here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to use semantic versioning.

## [Unreleased]

### Added

- Architecture overview and local-first trust model.
- Architectural decision record for the zero-dependency approach.
- Quality strategy, definition of done, and performance budget.

## [1.0.0] - 2026-09-11

### Added

- JSON formatting and minification.
- JWT payload inspection.
- Unicode-safe Base64 and URL codecs.
- UUID generation and SHA-256 hashing.
- Responsive light and dark interface.
- Command palette and keyboard navigation.
- Offline PWA support.
- Automated tests, CI, and GitHub Pages deployment.
